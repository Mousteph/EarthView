# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** option on the [EarthView Security tab](https://github.com/Mousteph/EarthView/security). Do not publish an issue or pull request containing exploit details before maintainers have had a chance to respond.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Do not include real NASA FIRMS keys, personal data, or unrelated secrets in a report.

## Maintainer setup

Enable GitHub private vulnerability reporting in the repository's Security settings before inviting public security reports. Acknowledge reports and coordinate disclosure with the reporter; response times depend on maintainer availability.

## Supported versions

Until tagged releases are published, security fixes are considered for the default branch. No versioned release support window is defined yet.
